# ARP Spoofing Simulator
simulation of ARP cache poisoning.

It models a small network containing:

- Client
- Gateway
- Attacker


## Files

- `main.py` - complete simulator.
- `README.md` - project overview and usage.
- `explanations.md` - detailed explanation of the ARP concepts and code.

## How to run

```bash
python main.py
```

Use:

```text
1 - Show ARP table
2 - Simulate ARP poisoning
3 - Reset ARP table
4 - Exit
```
